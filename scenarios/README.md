# 场景库索引

场景文件统一放在本目录，字段定义见 `src/domain/scenario/ScenarioTemplate.h` 与
`docs/软件架构设计.md` 的场景模板一节。所有场景都能被
`adasim_batch --once` 直接加载评价，也能在界面上加载运行。

## 与五组实验的对应关系

| 场景文件 | 工况 | 服务实验 | 关键考核量 |
| --- | --- | --- | --- |
| `following_lead.json` | 直道跟车 | E4 闭环精度 | 横向误差 RMS、速度误差 RMS、最小净距 |
| `curve_tracking.json` | 半径约 300 m 的左弯 | E4 闭环精度 | 横向误差 RMS ≤ 0.3 m、航向误差 |
| `lead_emergency_brake.json` | 前车以 6 m/s² 紧急制动 | E4 闭环精度 | 最小净距、峰值减速度、是否追尾 |
| `cut_in_simple.json` | 邻道车切入但不制动 | E4 闭环精度 | 最小净距、TTC、最大减速度 |
| `cut_in_brake.json` | 切入后继续制动 | E4 / 演示 | 组合工况下的兜底接管 |
| `static_obstacle.json` | 同车道静止故障车 | E4 补充 / 演示 | 静止目标的可检出距离与停车精度 |
| `replay_mixed.json` | 跟驰 + 切入 + 匀速三车混合 | E3 回溯一致性 | 回溯前后位姿偏差 |
| `latency_probe.json` | 轻载稳态跟车（低点云密度） | E2 通信时延 | 控制回路往返时延 |
| `low_friction_rain.json` | 附着 0.35、能见度 0.55 | E5 场景生成 / 兜底演示 | 制动距离随附着的变化 |
| `stress_dense.json` | 24 车道密排车阵、十万点 | E1 渲染性能 | 帧时间分位数、内存峰值 |

## 作者须知

- `trigger` 是行为开始的仿真时刻，必须小于 `durationSeconds`，否则校验直接拒绝——
  "永远不会发生的行为"比报错更难排查。
- `brake` 行为必须给正的 `brakeAccel`；`cut_in` 不写 `targetY` 时默认朝自车车道切一条，
  起点与目标横向坐标差不足 0.5 m 会被判为"没有真的换道"。
- 弯道场景的 `curvature` 单位为 1/m，正值表示左弯（圆心在 +y 侧）。
  当前只有自车与算法侧按曲率生成参考路径，参与者仍按各自航向直线推进，
  因此弯道场景里只放静止或短时存在的参与者，避免前车"开出路面"。
- `egoPose`（可选）给自车一个初始位姿，缺省为原点朝 +x。想考察"横向偏差
  收敛"就必须用这个字段：自车从参考线正中起步时，直道的横向误差恒为 0，
  那个指标没有区分度。`following_lead.json` 用 0.3 m 偏置做这件事。
- 所有参与者初始位置距原点不得超过 200 m，否则视为不在雷达量程内。
